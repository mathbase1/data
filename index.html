Developer notes — do not include on real pages

Prototype inputs: this page scans compatible browser-storage records and otherwise uses labelled sample exam attempts. Its totals, changes, filters, graphs and priorities are deterministic JavaScript calculations and do not use AI.

Suggested production data contract: fetch exam attempts for the authenticated account from the backend. Each record should include attempt ID, exam ID and version, subject, completion date, raw score, available marks, percentage, answered and unanswered counts, duration, topic-level totals, question-level answers, correct answers and stored feedback.

Update flow: refresh after a successful exam submission, when filters change, on page load and when the backend result version changes. Paginate large histories and perform account ownership checks on every attempt-detail request. Never trust a learner ID supplied by the browser.

Production access: protect summary and attempt-detail APIs with the real authenticated session. Logout must revoke that session and return to the production login route. The current GitHub destinations exist only to demonstrate this prototype.
